# WAPO design direction

- Audience: one person running a local WhatsApp Web client on desktop or phone.
- Visual language: warm paper surfaces with deep green used only for WhatsApp connection and send actions; this keeps the interface calm while making connectivity legible.
- Typography: DM Sans for compact, readable chat metadata; Manrope for the short WAPO wordmark and conversation title to give the product a distinct voice.
- Layout: persistent conversation list on wide screens, one-screen-at-a-time chat navigation on mobile to preserve reading width and thumb reach.
- Motion: hover/focus transitions only; no background animation, to keep the client responsive and low-distraction.
- ENERGY 2 / RHYTHM 1 / MOTION 1.
